# 日時表示（Time Display）

「最短◯月◯日(✕)△:△△」のような日時を、見た人の現在時刻から自動計算して表示するWordPressプラグイン。
計算は閲覧者のブラウザ側で日本時間（Asia/Tokyo）固定で行われるため、ページキャッシュの影響を受けません。

## インストール

このフォルダごと `wp-content/plugins/` に入れて、管理画面で有効化。

## 使い方

1. 管理メニューの **「日時表示」→ 新規追加** でパーツを作成（タイトルは管理用のメモ。表示には出ません）
2. 画面のフォームで文言や計算ルールを設定して保存
3. 画面上部に出るショートコード **`[time_display id="123"]`** をコピーして、表示したい場所（投稿・固定ページ・ウィジェット等）に貼り付け

パーツは何個でも作れるので、**1サイト内で場所ごとに違う設定**で使えます。ショートコードは「日時表示」の一覧画面にも表示されます。

```
[time_display id="123"]                     → そのパーツの設定で文言つきボックス表示
[time_display id="123" display="inline"]    → 日時のみ（文中埋め込み用）
[time_display]                              → id省略時は共通設定（config.json / デフォルト）で表示
```

`[fastest_time]` は旧名の互換エイリアスとして動作します。

## 設定できる項目（パーツ編集画面）

- **文言** — 日時の上下に出す文言、日時の直前につく文字（「最短」。空欄も可）
- **表示する時刻の計算** — 「今から何分後を表示するか」「何分単位に切り上げるか」
  - 例: 60分後・30分切り上げ → 15:02に見た人には「16:30」
- **時間帯ごとの表示ルール** — 時間帯ごとに「計算して表示」か「決まった時刻を表示（当日/翌日/翌々日の◯時）」かを行で設定。行の追加・削除自由
  - デフォルト: 0:00〜8:59 → 当日10:00 ／ 9:00〜19:59 → 計算して表示 ／ 20:00〜23:59 → 翌日10:00
編集画面は「**設定**」「**見た目**」「**JSON**」の3タブ構成で、右側に入力内容がリアルタイムで反映されるプレビューが常時表示されます。

### 「見た目」タブ

**かんたん設定（CSS不要）**
- 文字の位置（左寄せ／中央／右寄せのボタン）
- 日時の色・文字サイズ、文言の色（カラーピッカー）
- 背景色、枠線の色・太さ（0で枠線なし）、角の丸み

**こだわり設定（CSS）** — かんたん設定で足りない場合はCSSを直接記述。かんたん設定より優先されます。

### 「JSON」タブ

パーツの全設定をJSONで表示・編集できます。

- 現在の設定がJSONで表示される（バックアップ・別パーツへのコピーに）
- JSONを貼り付けて「保存時にこのJSONを設定へ反映する」にチェック → 更新で一括反映（フォーム入力より優先）
- JSONが壊れている場合はエラー表示され、フォームの内容で保存されます

### CSSクラス一覧

| クラス | 対象 |
| --- | --- |
| `.ftd-box` | ボックス全体（枠・背景） |
| `.ftd-before` | 日時の上の文言 |
| `.ftd-main` | 日時の行 |
| `.ftd-time` | 日時の文字そのもの（inline表示のときはこれだけ） |
| `.ftd-after` | 日時の下の文言 |
| `.ftd-123` | 投稿ID 123 のパーツだけを指す固有クラス |

テーマの「追加CSS」（外観 → カスタマイズ）から同じクラスを使ってサイト全体で上書きすることもできます。

## JSONでの共通設定（任意・開発者向け）

id を付けないショートコードや、パーツで設定していない項目のデフォルト値は、次の優先順で決まります：

1. テーマ（子テーマ）フォルダの `time-display.json`
2. プラグインフォルダの `config.json`
3. 内蔵デフォルト

さらにPHPの `ftd_config` フィルターでも上書き可能。書式は `config.json` を参照。

## ファイル構成

- `time-display.php` — プラグイン本体（投稿タイプ・ショートコード・PHPフォールバック計算）
- `time-display.js` — ブラウザ側の日時計算と自動更新（パーツごとの設定は data 属性で受け取り）
- `time-display.css` — ボックスの見た目（自由に上書き可）
- `config.json` — 共通デフォルト設定（元仕様「表示ルール」表のJSON版）
- `examples.json` — 元仕様「具体例」表のJSON版（テストケースとして利用可能）
